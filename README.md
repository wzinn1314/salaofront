# Jaiane Neves — Beleza & cuidado

Site responsivo em HTML, CSS e JavaScript, sem dependências de instalação. Abra `dist/index.html` no navegador.

Paleta 60/30/10: branco predominante, creme como apoio e dourado como destaque. Serviços, valores e horários são demonstrativos; edite `dist/script.js` para personalizá-los.

O agendamento usa localStorage: permite reservar, consultar e cancelar neste navegador, verificando sobreposição de horários e duração dos serviços. Não envia mensagens ou reservas ao salão e não sincroniza clientes. Para operação real, conecte um backend com banco de dados e validação de disponibilidade no servidor. Nome e telefone são armazenados localmente; cancelar a reserva remove esses dados.

A fotografia é carregada do Unsplash; as fontes, do Google Fonts. Sem internet, as fontes alternativas continuam disponíveis.
